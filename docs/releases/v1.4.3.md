# Glasswork v1.4.3

This release makes imported PBI work easier to scan in My Day and improves task discovery and app updates.

## Changes

- Groups imported child Tasks beneath their PBI container in My Day, including tasks whose `parent` uses the PBI's ADO work-item ID or URL.
- Finds Tasks correctly when Glasswork is configured with the Obsidian Vault root rather than the task directory itself.
- Installs future app updates from verified GitHub Release packages with rollback protection.
- Keeps Automation Review Queue timestamps consistent when services use an injected clock.

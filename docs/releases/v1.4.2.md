# Glasswork v1.4.2

Glasswork now provides safer agent-driven workflows through revision-aware,
atomic Vault mutations, alongside richer planning, hierarchy, review, and
artifact experiences.

## Changes

- **Safe, transactional agent workflows.** Task-bearing reads expose opaque
  Resource Revisions, clients can discover supported capabilities, and agents
  can query dependency-ready work or commit complete Task graphs atomically.
  Mutations are idempotent, recoverable, and fail closed when Vault content has
  changed.
- **Stronger Task planning and hierarchy.** Glasswork distinguishes PBIs from
  Tasks, groups My Day work under parent PBIs, supports blocked workflows,
  children and subtasks, saved views, due and scheduled fields, and richer
  actionability signals.
- **Richer Artifacts and agent context.** Multi-format Artifacts gain safe
  previews and sharing actions, while expanded MCP tools expose activity,
  backlinks, context bundles, links, subtasks, overdue work, and My Day
  operations.
- **Glasswork MCP 0.9.0 contract.** The independently versioned MCP tool now
  carries the breaking fail-closed mutation contract completed by PRD #404.

## Validation

- Release workflow gates run: release-input validation, release-script tests,
  serial Core tests, and a Windows Release x64 app build.

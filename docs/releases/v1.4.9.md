# Glasswork v1.4.9

MCP updates now explain how to resolve an active-tool lock without exposing
terminal formatting or PowerShell implementation details.

## Changes

- When `glasswork-mcp` is still in use by a Copilot or agent session, Settings
  shows one clear instruction to close active sessions and retry.
- Removed raw ANSI control codes, script locations, and PowerShell stack output
  from MCP update failures.
- Preserved unrelated uninstall errors so genuine disk or package problems
  remain diagnosable.

## Validation

- Release workflow gates run.

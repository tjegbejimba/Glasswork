# Glasswork v1.4.8

Glasswork can now keep the desktop app and its agent tool current independently,
while Research context selection and provenance are easier to inspect.

## Changes

- Added separate app and `glasswork-mcp` GitHub Release streams. Settings can
  detect and install a verified MCP-only update without restarting Glasswork.
- Added page search to the Research context picker, including stable selection
  restoration and a clear no-results state.
- Improved Research provenance so raw Source pages resolve through their
  summaries instead of surfacing unresolved source material.
- Fixed the Research drawer close button overlapping nearby content.

## Validation

- Release workflow gates run.

# Glasswork v1.4.4

This release improves task-edit reliability, strengthens task query consistency, and preserves diagnostics when Glasswork encounters an unexpected crash.

## Changes

- Prevents Task Detail from crashing when an external task update arrives while an editable field still has focus, with safe Reload and Keep Mine conflict handling.
- Records durable crash reports under `%LocalAppData%\Glasswork\logs`, including app and runtime context, while retaining the ten most recent reports.
- Keeps task query snapshots and backlink counts consistent across task creation, external edits, and file renames.

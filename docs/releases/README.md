# Glasswork release notes

Release notes are committed by a Release PR before Release publication. Each
published version uses `docs\releases\vX.Y.Z.md`; the Release workflow validates
that the file exists and uses it as the GitHub Release body.

Use this template:

```md
# Glasswork vX.Y.Z

One short summary paragraph.

## Changes

- Grouped user-facing changes.

## Validation

- Release workflow gates run.
```

# Glasswork v1.4.10

Glasswork can now activate verified MCP updates for new agent sessions without
interrupting sessions already using an older build, alongside new Planner
foundations for sizing and recovering daily scope.

## Changes

- MCP updates install immutable versions side by side and atomically update the
  Copilot Glasswork command. Existing sessions keep running; new sessions use
  the verified update immediately.
- Added version-tolerant Task and Subtask Size persistence plus canonical
  actionable-leaf Planner scope across Core, search, My Day, and MCP.
- Added Planner Profile confirmation, Not today, undo, session recovery, and
  rollover/conflict protections behind the Planner delivery path.

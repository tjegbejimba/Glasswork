# Glasswork v1.4.5

This release adds a complete cancelled-task lifecycle, safer permanent deletion, and authoritative reconciliation for ADO-removed work.

## Changes

- Cancel Tasks with an optional reason, review them in the Work Log archive, and restore them to active work when needed.
- Permanently delete cancelled Tasks through a guarded preflight that confirms the affected Task tree, Artifacts, and incoming links before applying the change.
- Reconcile ADO items in the Removed state authoritatively by cancelling matching Glasswork Tasks, while preserving completed work and supporting restoration when work resumes.
- Retire the broken My Day roll-forward migration so date-scoped pins expire naturally instead of being moved forward at startup.

## Validation

- Release inputs, serial Core tests, and the Windows x64 Release app build passed locally; release workflow gates run before publication.

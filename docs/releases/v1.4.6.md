# Glasswork v1.4.6

This release keeps hard deletion available for valid Tasks when unrelated malformed Task identities exist elsewhere in the Vault.

## Changes

- Hard deletion of a valid Task is no longer blocked by unrelated filename/frontmatter ID mismatches, while malformed identities related to the selected deletion still fail closed.

## Validation

- Release inputs, serial Core tests, the Windows x64 Release app build, and the relevant visual smoke run locally; release workflow gates run before publication.

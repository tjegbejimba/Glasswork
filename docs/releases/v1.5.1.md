# Glasswork v1.5.1

Glasswork now reliably reopens after Restart to update when another updater is already active.

## Changes

- Wait for the active updater to finish, then relaunch the installed app instead of leaving Glasswork closed.
- Add regression coverage for the updater mutex contention path.

## Validation

- Release publication inputs, Core tests, and the Windows Release x64 app build validated locally.
- Release workflow gates run.

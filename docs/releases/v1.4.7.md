# Glasswork v1.4.7

This release introduces first-class, governed Research work across the app, MCP, Tasks, and Wayfinder.

## Changes

- Browse a first-class Research catalog and choose durable context pages with safe topic add/remove, live refresh, deep links, and verified adaptive narrow, accessible, and high-contrast layouts.
- Launch scoped Research Sessions with bounded, durable context through the MCP 0.10.0 Research append/session surface.
- Follow Research as it develops through live Change Logs and History.
- Connect Tasks and Wayfinder maps as Related Work, and reliably open ADO-linked child Tasks from their parent.

## Validation

- Release inputs, the full serial app test suite, and the Windows x64 Release app build run locally; release workflow gates run before publication.
